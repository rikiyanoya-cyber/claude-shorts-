# 難読地名クイズ Shorts フォーマット（2026-11-27 確定。見本＝①「国立・東雲・高輪」）

作り方：`bash build_nandoku.sh <番号> <地名1> <地名2> <地名3>`

## 画面
- 縦1080×1920、約29秒。背景はオーナーの和紙画像に、墨の二重枠と四隅の深紅の角。
- 文字はすべてプログラムで組む（Noto Serif CJK JP＝明朝の太字）。色はクリーム／墨 #2B2620／深紅 #9E2A24。
- 大事な文字はShortsの下の重なり（タイトル・チャンネル名）より上に置く。

## 流れ
| 時間 | 中身 |
|---|---|
| 0.0 | 出題音（オーナー「Quiz-Question02 Low」）と赤い大きな「？」 |
| 0.7 | 声「あなたはわかるかな」＋文字 |
| 2.5 | 声「難読地名クイズ」＋赤い札「難読地名／クイズ」 |
| 4.1〜 | 第一問〜第三問、各6.8秒 |
| 終わり4.6秒 | 声「いくつ読めましたか」→「答えはコメント欄で」＋赤い札と↓ |

## 1問の中
- 「第N問」の札 → 地名を大きく（和太鼓「ドン」）→「なんと読む？」
- 制限時間5秒：ストップウォッチの赤が減る＋「のこり N 秒」（残り3秒から赤）。音はオーナーのタイマー「Timer02 Timbre1」の頭5秒（1秒ごとの強い音が数字に合う）。
- 0で「時間です！」とおりん「チーン」。
- 答えは動画に出さない。投稿後に固定コメントで出す。

## 音
- 声：オーナーのナレーション（Hatake Kohei）の4セリフを切って配置。
- BGM：オーナー「Warm Trivia Breeze」。出題音のあとに入り、声の間は少し下げる（声より約19 dB下）。
- 効果音：切り替え「シュッ」、和太鼓、おりん、終わりの札で琴っぽい和音（以上はこちらで合成）。
- 仕上げ：−14 LUFS／ピーク−1.5 dB以下（高域を12 kHzで丸めてから圧縮→リミッター、AAC 192k）。
