# 研究×物語アニメ　フォーマット（第1本で確定、2026-11-16）

第1本「厳しい親が、何も知らなかった理由」で本人と決めた形。次の回もこれで作る。
コード：`src/companies/Fam1Episode.tsx`（構成）／`scripts/fam1/`（切り抜き・間・音の重ね合わせ）。

## 1. 画面の作り
- 1920×1080、30fps。キャラは紺背景の生成画像を切り抜いて使う（`cutout.py`）。造形は元絵が正。
- 地面は2種類：
  - **舞台**（紺の地＋スポットライト＋床の光だまり＋光の粒）：説明・数字・比較。
  - **線画の場面**（セピアの細い線）：物語の場所。新しい場所に変わったときだけ線が描かれて出る。
- 戻ってくる装置：スマホの地図と光る点、夜の時刻の目盛り（時計の針つき、金色の線で横に拭き取って入る）。
- 数字はカウントアップ＋下に小さく出典（著者・年）。大きな言葉は1文字ずつ浮かぶ。大きな人数は小さな人の群れ。
- 説明のための図（研究の数値そのままでないもの）には「※説明のためのイメージ」と書く。
- **色分けは全編で統一**：管理する親（父親A）＝青／話を聞く親（父親B）＝黄色。B側の場面は背景も黄色にする。
- 左右の比較は、当番でない側を強く暗くする（黒を約74%かぶせる）。
- 単調にしない動き：キャラは出るときに少し弾む＋ゆっくり揺れる。カメラは場面ごとに「寄る／右に流れる／左に流れる」を順に変える。
- セリフは吹き出しで出し、その間は下の字幕を出さない。

## 2. 字幕
- 下に白の太字（Noto Sans JP）、数字と大事な言葉だけ金色。
- **音声どおりに出す**（台本と音声が違えば音声が正）。長い文は「。」で区切り、長さに合わせて時間を割る。
- 台本と音声の照合は、1文ずつ区切って聞き直してから決める（まとめて聞くと言葉が抜けることがある）。

## 3. 音
- ナレーションは手を入れない。締めの「今日のお話はこれで以上です。」の前に**1秒の間**を足す。
- **BGMは1曲だけ**（第1本は「Night Walk Home」）。全編をつないで流し、**声より20dB低い一定の大きさ**。最初2秒で入って、最後3秒で消える。
- 効果音（柔らかい記号っぽい音、本物っぽい音は使わない）：
  - 画面の切り替わりの「ふわっ」は**章が変わる所だけ**（毎回は鳴らさない）。
  - 時計の「チッ」（時刻の目盛りで5回）、カウントアップ音（数字）、スマホの通知、文字を打つ音、柔らかい雨、ノック、低い「ドン」（怒鳴る・山場）、あたたかい「キラン」。
  - 項目が出るたびの「ポン」は**鳴らさない**。
  - 静かに見せる所（秘密の重さ、回想、締めの言葉）は音なし。
- 全体の音量は −14 LUFS。

## 4. 終わり方
- ラスト約18秒は、左右に線で区切った**止まった絵**：左＝青の背景に怒る親と縮こまる子、右＝黄色の背景に笑う親と子。チャンネル登録の演出はなし。
- 最後のひと言の約0.5秒後に、**テレビを消す演出**（上下につぶれて横線→点→真っ暗）＋アニメっぽいテレビを消す音（声より8dB低め）。

## 5. 納品
- 3つのチェック（形式／完成ファイルのコマ／音量とズレ）をしてから送る。
- スマホで受け取れるよう、HEVC で65MB以下にした版を送る（第1本は約41MB）。
