# Sound effects library (ElevenLabs)

Sound effects generated with ElevenLabs Sound Effects. Shared across ZERO HOUR, だってよ。 and NowClub.
All files are MP3. Gains are what worked in past mixes (voice ducked over SFX with sidechain compression, final loudness -14 LUFS).

When a new sound is generated, add the file here with a short snake_case name and add a row with its prompt.

## Making more

Generate on the ElevenLabs web app (`https://elevenlabs.io/app/sound-effects`; the mobile app has no Sound Effects menu), or with the API (`text_to_sound_effects.convert`) when `ELEVENLABS_API_KEY` is available. Requested durations are not always respected (some came back at 1s), so check the length after downloading.
